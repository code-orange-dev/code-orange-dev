# 🟠 Code Orange Dev School

Code Orange Dev School is a Bitcoin-only developer education program. Most sessions run online, with some in-person workshops. We run study cohorts, workshops and meetups for developers and technical Bitcoiners who want to learn Bitcoin and contribute to its open-source software. All curriculum is free and CC0-licensed.

---

## Start here

1. **Join the [Discord](https://discord.gg/xd6dmPF9bA)** and say hi.
2. **Pick a program** that matches your level: [Bitcoin Dojo](https://github.com/code-orange-dev/curriculum/tree/main/bitcoin-dojo) (cryptographic primitives), [rawBit](https://github.com/code-orange-dev/curriculum/tree/main/rawbit) (raw transactions), [Decoding Bitcoin](https://github.com/code-orange-dev/curriculum/tree/main/decoding-bitcoin) (protocol and Bitcoin Core workflows), or the [Privacy Track](https://github.com/code-orange-dev/curriculum/tree/main/privacy-track) (drop-in sessions).
3. **Find a first contribution.** The Privacy Track explains [how to find a current beginner issue](https://github.com/code-orange-dev/curriculum/blob/main/privacy-track/ISSUE_POOL.md) and check it's still open before you start.

## Programs

Full syllabi, exercises and facilitator guides are in the **[curriculum repo](https://github.com/code-orange-dev/curriculum)**.

- **[Bitcoin Dojo](https://github.com/code-orange-dev/curriculum/tree/main/bitcoin-dojo)** *(7 weeks)*: build Bitcoin's cryptographic primitives with Jimmy Song's [Programming Bitcoin](https://github.com/jimmysong/programmingbitcoin). Exercises are graded against real mainnet transactions.
- **[rawBit Study Cohort](https://github.com/code-orange-dev/curriculum/tree/main/rawbit)** *(10 weeks)*: build raw transactions with [rawBit](https://github.com/rawBit-io/rawbit), an open-source visual transaction builder.
- **[Decoding Bitcoin](https://github.com/code-orange-dev/curriculum/tree/main/decoding-bitcoin)** *(8 weeks)*: transactions, Script, Taproot, PSBTs and the Bitcoin Core contribution workflow.
- **[Sovereign Bitcoiner](https://github.com/code-orange-dev/curriculum/tree/main/sovereign-bitcoiner)** *(5-10 weeks)*: full nodes, mining with BitAxe, multisig and inheritance planning.
- **[Privacy Track](https://github.com/code-orange-dev/curriculum/tree/main/privacy-track)** *(biweekly, drop-in)*: Silent Payments, chain analysis, coin selection, Payjoin, light clients, network privacy, CoinJoin and swaps, Lightning and ecash.
- **[Privacy Contributor Program](./privacy-contributor-program/)**: the program design for moving developers from study cohorts to sustained contribution in Bitcoin privacy projects, through reviewing, testing and contributing.
- **[Vibe Coding on Nostr](https://github.com/code-orange-dev/curriculum/tree/main/nostr-workshops)** *(monthly)*: building on Nostr with Lightning integrations.

### Workshops

Hands-on workshops in Bali and online, in English and Indonesian. Topics include BitAxe mining, multisig and key management, running a full node, ecash (Fedimint, Cashu), Nostr, BTCPay Server and privacy tools. Slides and guides are open-source (see below), and the [workshops repo](https://github.com/code-orange-dev/workshops) documents past sessions.
